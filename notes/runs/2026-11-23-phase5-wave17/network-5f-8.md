## Patterns proven

- **A member with an inline ctor fixes a store order that no init-list/body order can.** ClusterReplicationData
  0x005a0090: member ctors run before the outer body, and inside the member ctor the init list precedes the body
  (+4 then +0). Plain members always let VC9 schedule the bit-field `and` first.
- **Itanium primary vftables repeat overriders of secondary-base virtuals**; MSVC's do not. Mapping iOS slots
  onto MSVC slots means dropping OnReceive/UsesReliabilityLayer/OnInternalPacket (PluginInterface2),
  getMetric/getMetricValue (IMetric), terrainCellChanged (CellChangeListener) and getClassName; the rest map 1:1
  (Replicator: iOS 36..86 → PLAYER 30..74).
- **A shell-copy callee does not always cost the caller.** ItemSender::closePacket calls
  `RunningAverageTimeInterval<>::sample` at the shell address 0x00460e50 in 2013, yet scored 100 (our shell already
  instantiates it).
- **Scoring reads the sources at run time:** a round whose JSONs were made after Network sources changed (lines
  moved) reports every function below the edit as unpaired (`None`). Freeze sources until a round finishes.
