## Patterns proven

- **VC9 proves a same-TU callee nothrow and drops EH states.** Player::setCharacter's `STUB` body
  (`__declspec(noinline)`, defined above ~Player in Player.cpp) cannot throw, so ~Player lost the body's
  state (`mov [esp+..], 0x1b` before the call, `0x1a` after) and scored 91.3%. One opaque call in the stub
  (`Players::backendProcessing(this, false)`, in another TU) restores both stores: 91.3% -> 100% in PLAYER
  and STUDIO, with removeCharacter/onServiceProvider unchanged at 100%. A STUB stand-in that a later
  function in the same TU calls should contain at least one cross-TU call.
- **CrashReporter.cpp is `#pragma optimize("", off)` after its includes** (2016 has the same line):
  every member keeps an ebp frame and spills `this`, but small helpers (scoped_ptr::reset, strlen) are
  still expanded inline and the strsafe workers, defined in strsafe.h before the pragma, stay optimized
  (StringCchCopyA 0x0051f9d0).
- **Unoptimized frame layout follows the local variables' names.** PreventSetUnhandledExceptionFilter
  went 47.9% -> 100%, GenerateDmpFileName 53% -> 100%, ProcessException 84.7% -> 100% and
  LaunchUploadProcess 89.7% -> 100% only by renaming locals to the names of the public 2016 code
  (hKernel32, pOrgEntry, newJump, ...; dumpFilename, dumpFilenameLen; hFile, eInfo, msg, bytesWritten;
  filename, si, pi, cmd). Same statements, same declaration order. fixExceptionsThroughKernel (4 locals)
  matched with arbitrary names. In /Od code, take local names from the oracle before anything else.
- A noreturn call ends the function: `LONG r = f(info); _exit(1);` with no `return` matches
  TopLevelExceptionFilter; a `return r;` after `_exit` emits a dead `mov eax, [ebp-4]` even at /Od.
- `if (scoped_ptr)` at /Od compiles to `neg; sbb; neg; sub 1; cmp -1` (the null pointer-to-member is -1).
- RakNet's `UNASSIGNED_SYSTEM_ADDRESS` is a per-TU `const` object (internal linkage), so each user
  .obj has its own copy (Peer.obj's PLAYER 0x00ddf9b8); it pairs after a CSV regeneration.
