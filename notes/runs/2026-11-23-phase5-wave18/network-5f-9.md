## Patterns proven

- **A named `Time` local fixes both the frame and the copy order** (`Time now = Time::now<Benchmark>(); member = now;`):
  the temporary form reads the result through eax and shares a slot; dataOutStep 0x0059c060.
- **A named `Time::Interval` local makes VC9 `fld` the local** rather than `[eax]` (PacketJob::error 0x005c5900).
- **`if (x) return true; return false;` vs `return x;`**: the latter emits `xor eax,eax; cmp …,eax`, the former
  `cmp …,0` (isPropertyChangedPending 0x0058d430).
- **A class that adds the first `boost::unordered` user to an early Network .obj moves prime_list.** ConcurrentRakPeer.obj
  (linked before NetworkPacketCache.obj) became the supplier, and our link then placed the `"circular_buffer"`
  literal at prime_list's one-past-end, which reccmp names before `+end`: 15 PLAYER prime_list users lost 100
  (Players/Replicator/packet-cache/DataModel/ContactManager… ctors). Reverted; the layout is kept in a comment.
- **2013 `Security::Impersonator` is one pointer** (`previous`; heap `Context`), evidenced by onChildAdded's frame.
