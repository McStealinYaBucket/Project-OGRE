## Layouts proven (byte-identical ctor and dtor)

- **Server (0xb78)**: `std::set<std::string>` usedTickets 0xb00 and preusedTickets 0xb0c (2016 names);
  `boost::bimap<std::string, long>` at 0xb18 (0x54 bytes, core at 0xb30). iOS 10-29 instantiates
  `bimap_core<std::string, long>`, and the dtor frees the 0x38-byte header node from 0xb34. 0xae8 is the next
  script id (`long`, starts at 1, post-incremented into the bimap pair). 0xaec is `std::vector<int>`, assigned
  {1..17} from a stack array. The signals are 0xb6c/0xb70 `signal<void(shared_ptr<Instance>, FilterResult,

## Patterns proven

- **An implicit `const std::string&` conversion inside a pair constructor matches the original's temporary.**
  `bimap.insert(value_type("", id++))` is byte-identical. A named local string, `std::string("")`, and the
  2016 helper `registerLegalScript(const std::string&)` (in-class inline, or a member defined after the ctor) all
  differ, and VC9 never inlined the helper. The original's stack sharing gives it away: the string temp shares
  setName's slot, and the pair shares the runtime_error slot.
- **2013 code skips `Super::onServiceProvider` when the base's version is the empty inline Instance virtual.** No
  call is emitted, and writing the call reproduces this.
- **`shared_from_polymorphic_downcast<Stats::Item>(stats->findFirstChildByName(...))` reaches the
  `shared_static_cast<Instance, DescribedBase>` COMDAT** (0x005901e0, folded). The original Peer.cpp used the 2016
  helper unchanged.
- **A Roblox class can add a brand-new virtual with a RakPeer method's name.** ProfiledRakPeer's 2-argument
  `RunUpdateCycle` is not an override.
