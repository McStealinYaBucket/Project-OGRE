## Pattern / gotchas

- **A source file that was empty when a build dir was configured is not compiled until the dir is reconfigured**
  (`ogre_prior_sources` adds only non-empty files, so the CONFIGURE_DEPENDS glob does not catch it). build-nw had never
  compiled `Replicator.StreamJob.cpp`; its markers simply had no body in our map. Reconfigure (`cmake -S . -B <dir>`) after
  filling a previously empty `.cpp` (here StreamJob.cpp and NetworkFilter.cpp).
- **Never edit sources while a scoring run is in progress**: reccmp reads markers from the current source and maps them
  through the PDB's line records. One mid-run edit of Streaming.cpp/ServerReplicator.cpp turned a clean run into ~30 false
  Network losses after CSV regeneration.
- Inserting a STUB above `~Replicator` shifts the 348/350 asserts; Replicator.cpp's convention is to place new STUBs after
  the dtor as listed descents and trim the big blank run before 2750 (assert_lines `--apply` only handles the plain
  RBXASSERT anchors, not the OGRE_PLAYER/STUDIO_ASSERT ones).
- 2013's `Guid::Scope` default ctor does not initialize (readInstanceRemoval, iOS readInstanceRemoval and
  readPropAcknowledgement leave the `Guid::Data` local raw).
