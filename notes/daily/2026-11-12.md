## 17:15 Out-of-memory crashes, fixed; `phase4-core2` restarted again

- **What happened:** the 16:19 stop and the 17:05 stop were both out-of-memory kills, and each one also took the user's VS Code down. A python process grew to 22 GB and then 13 GB, almost certainly `tools/ida/import_types.py dump`, which parses the whole recompiled PDB's type stream. When the kernel kills anything inside VS Code's systemd scope, systemd stops the whole scope, and that scope includes Claude Code and every agent.
- **Fix:**
  - `tools/capped.sh` runs a command in its own scope with a memory cap. Tested: a 400 MB job under a 200 MB cap was killed alone, and VS Code survived.
  - CMake now limits each build tree to 6 parallel compiles (`OGRE_COMPILE_JOBS`).
  - The workflow's agents must run every heavy command capped and make `import_types.py` parse only the classes it needs.
  - Measured: reccmp itself peaks at 0.7 GB.
- **Relaunched** `phase4-core2` (still wf_fef33d15-1aa) with these rules added.
